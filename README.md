# Anass Asrir — Portfolio & Blog

> **Architecte SDET & Concepteur de Solutions Digitales.**
> Portfolio personnel monochrome radical & blog technique, développé avec Next.js 15, React 19, TypeScript et Tailwind CSS.

---

## ⚡ Présentation

Ce dépôt contient le site personnel d'**Anass Asrir** (`anassasrir.com` / `anassasrir.fr`).
Il réunit :
* **Un univers visuel brutaliste / suisse** : Contrastes nets, noir absolu (`#000000`), polices `Space Grotesk` et `Space Mono`.
* **Une vitrine de réalisations d'envergure** : Projets industriels QA (QA-Hub, frameworks E2E), projets agronomiques 4D (Couleurs au Potager), applications ludo-éducatives (JoliPas) et initiatives communautaires (Les Equier'mômes).
* **Un blog de réflexions techniques** : Retours d'expérience sur le Shift-Left, les agents IA, le développement moderne et le design épuré.

---

## 🛠️ Stack Technique

* **Framework :** [Next.js 15](https://nextjs.org/) (App Router, Server Components)
* **Bibliothèque UI :** React 19 + TypeScript
* **Styling :** Tailwind CSS + CSS custom tokens (brutaliste monochrome)
* **Typographie :** Space Grotesk & Space Mono (Google Fonts)
* **Icônes :** Lucide React
* **Gestionnaire de paquets :** `pnpm`

---

## 🚀 Démarrage Rapide

### Prérequis
* Node.js >= 20.x
* pnpm >= 9.x

### Installation
```bash
pnpm install
```

### Lancer en développement (Localhost)
```bash
pnpm dev
```
Ouvrez [http://localhost:3000](http://localhost:3000) dans votre navigateur.

### Build de production
```bash
pnpm build
pnpm start
```
